# 地图编辑器与自定义编辑器元素说明

本文档说明当前版本中 `editor.html` 地图编辑器和 `custom-editor.html` 自定义编辑器的每一个主要界面元素、输入项、按钮和动态面板的用途。两个编辑器的数据最终都会影响战斗页面：地图编辑器产出地图 JSON，自定义编辑器产出干员与敌人模板 JSON。

## 地图编辑器

地图编辑器用于制作和调整关卡地图，包括地形、可部署属性、敌人路径、路径节点动作、出怪时间轴，以及地图 JSON 的导入导出。

### 顶部栏

`MAP EDITOR / FIELD TEST` 是页面标识，用于区分当前处于地图编辑器。

`返回战斗` 会跳转回战斗页面 `/`。如果地图有未保存修改，浏览器离开页面前会触发保存提醒。

`自定义编辑器` 会跳转到 `custom-editor.html`，用于编辑干员和敌人模板。

`保存到地图库` 会将当前地图保存到浏览器 `localStorage` 中的自定义地图库。保存后可在首页地图管理框中选择、编辑或删除。

`导出` 会把当前地图状态转换为格式化 JSON，并写入右侧 JSON 文本框。它不会下载文件，只是生成可复制或可检查的 JSON 内容。

`导入` 会读取右侧 JSON 文本框中的内容，解析为地图并加载到编辑器。导入时会经过地图规范化与校验，旧版 `v1.0` 地图也会转换为 `v2.0` 结构。

`下载 JSON` 会把当前地图导出为一个 `.json` 文件，文件名使用地图 ID。

### 左侧：格子工具

`路径` 是地面路径格。敌人路径点必须落在路径格上，地面干员也只能部署在允许部署的路径格上。选中该工具后，在画布上点击或拖拽会把格子刷成路径。

`高台` 是高台部署格。狙击、术士、医疗以及高台自定义干员通常部署在这里。选中后刷格会把格子改为高台。

`障碍` 是不可部署、不可作为敌人路径点的阻挡地形。把路径格刷成障碍时，该格上的路径点和禁部署元数据会被清理。

`允许部署` 是路径格部署属性刷子。它不会改变格子地形，只会移除该路径格的禁部署标记。非路径格使用该刷子不会产生部署属性。

`禁止部署` 是路径格部署属性刷子。它不会改变地形，只会把路径格标记为不可部署。编辑器和战斗页面会在该格上显示红色叉号。入口、出口本身始终禁止部署，不需要额外标记。

### 左侧：地图属性

`名称` 是地图展示名称，会显示在战斗页面和地图库中。

`ID` 是地图的唯一标识，导出文件名、地图库去重和覆盖都依赖它。建议使用小写英文、数字、短横线或下划线。

`宽度` 是地图横向格子数量，范围为 3 到 30。修改后会调整网格宽度，超出新边界的路径点和地块元数据会被裁剪。

`高度` 是地图纵向格子数量，范围为 3 到 20。修改后会调整网格高度，超出新边界的数据同样会被裁剪。

`初始费用` 是战斗开始时玩家拥有的部署费用。

`费用上限` 是费用自然回复、击杀奖励和技能回费可达到的最大值。

`基地生命` 是关卡生命值。敌人进入终点时会按敌人的目标价值扣除生命。

`总波次` 是关卡显示和结算用的总波次数。更新时间轴事件时，系统会自动保证总波次不小于已有事件中的最大波次。

### 中央画布

中央画布是地图主编辑区域。

普通左键点击或拖拽会用当前工具连续编辑格子。选择地形工具时会改地形；选择部署属性工具时会改变路径格是否可部署。

按住 `Shift` 后拖拽会进行矩形框选，松开鼠标时一次性修改框选范围内的所有格子。

鼠标悬停格会高亮显示，框选时会显示预览区域。

如果当前选中了某条路径，使用 `路径` 工具刷路径格时，会自动把新路径格按行优先顺序追加为该路径的路径点。

路径线会连接当前路径点。路径起点显示为入口标记，终点显示为出口标记。路径节点上的黄色圆点表示该节点存在路径节点动作。

### 右侧：路径面板

路径面板用于管理敌人移动路线。地图至少需要一条路径才能用于战斗。

`新增路径` 会创建一条新路径，并自动选中它。之后点击或刷路径格即可给这条路径添加路径点。

`删除末点` 会删除当前选中路径的最后一个路径点。删除后路径的入口和出口会重新根据剩余点位计算。

路径列表中每一行代表一条路径：

- 路径选择按钮用于切换当前选中路径，按钮边框使用路径颜色。
- 路径名称输入框用于修改路径展示名称。
- 路径颜色输入框用于修改路径线、时间轴预览事件条等使用的颜色。
- 点数文本显示该路径当前拥有多少个路径点。
- `删除` 会删除整条路径，同时移除引用该路径的时间轴事件。

路径点顺序就是敌人的移动顺序。第一个点是入口，最后一个点是出口，中间点可用于设置节点动作。

### 右侧：路径节点动作

路径节点动作会在敌人移动到某个中间路径点时触发。只有至少 3 个路径点的路径才有中间节点，因此才能设置节点动作。

`添加停顿` 会给当前路径添加一个默认停顿动作。敌人到达指定节点后会暂停一段时间再继续移动。

`添加攻击模块` 会给当前路径添加一个默认攻击模块动作。敌人到达指定节点后，在持续时间内获得一个额外远程攻击模块。

`添加防御模块` 会给当前路径添加一个默认防御模块动作。敌人到达指定节点后，在持续时间内获得防御或法抗加成。

每条节点动作包含以下字段：

`节点` 选择动作触发的中间路径点。列表以 `#序号 (x,y)` 显示，序号按路径点顺序计算。入口和出口不能作为节点动作目标。

`类型` 选择动作类型，可在停顿、攻击模块、防御模块之间切换。切换类型会替换该动作的字段结构。

停顿动作的 `停顿秒数` 表示敌人在该节点停止移动的时间。

攻击模块动作的 `持续秒数` 表示模块存在多久；`伤害类型` 可选物理、法术、神经；`伤害值` 是组件伤害数值；`攻击间隔` 是额外攻击模块的攻击周期；`范围半径` 是额外攻击模块的菱形攻击范围半径。

防御模块动作的 `持续秒数` 表示加成存在多久；`防御增量` 会提高物理减伤中的防御值；`法抗增量` 会提高法术抗性，法抗按 0 到 100 的百分比减算。

`删除` 会移除该路径节点动作。

### 右侧：时间轴

时间轴决定敌人何时、以什么数量、沿哪条路径出现。

时间轴预览顶部显示从 `0s` 到当前预估总时长的时间范围。每一行对应一个波次，事件条的位置表示开始时间，长度表示该事件持续出怪的时间跨度。事件条颜色来自其选择的路径颜色。

`新增出怪事件` 会创建一条新的出怪事件，默认使用当前选中路径或第一条路径。

每条出怪事件包含以下字段：

`波次` 是该事件所属波次，用于显示和关卡进度统计。

`时间` 是事件开始时间，单位为秒。

`敌人` 是要生成的敌人类型。下拉列表来自当前敌人目录，包含默认敌人和自定义敌人。如果导入地图引用了当前目录不存在的敌人，列表会保留一个缺失项提示。

`数量` 是该事件总共生成多少个敌人。

`间隔` 是同一事件中相邻敌人的生成间隔，单位为秒。

`路径` 决定这批敌人沿哪条路径移动。

`删除` 会移除该出怪事件。

### 右侧：JSON 面板

JSON 文本框用于查看、复制、手动编辑或粘贴地图 JSON。

`导出` 会把当前地图写入这个文本框。

`导入` 会从这个文本框读取地图。

校验面板显示当前地图是否有效。有效时显示“地图有效”，无效时显示具体错误，例如路径点不在路径格上、时间轴引用不存在的路径、地图尺寸不匹配等。

### 地图编辑器保存与离开提醒

只要编辑器内产生未保存修改，离开页面时会提示“地图有未保存修改”。导出、导入、下载和保存到地图库会根据操作结果更新脏状态。实际长期保存建议使用“保存到地图库”或“下载 JSON”。

## 自定义编辑器

自定义编辑器用于创建和维护干员模板与敌人模板。保存后的数据位于浏览器 `localStorage`，战斗启动时会合并默认目录和自定义目录。

### 顶部栏

`CUSTOM DATA / FIELD TEST` 是页面标识，用于区分当前处于自定义数据编辑器。

`返回战斗` 会回到战斗页面。

`地图编辑器` 会跳转到地图编辑器。

`保存` 会把当前自定义干员和敌人数据保存到 `localStorage`。战斗页面加载时会自动读取这些数据。

`导出` 会把当前自定义目录序列化为 JSON，并写入右侧 JSON 文本框。

`导入` 会读取右侧 JSON 文本框中的自定义目录 JSON，校验通过后替换当前编辑状态。

### 左侧：模板面板

`干员` 和 `敌人` 是模板类型切换按钮。选择干员时，中间表单显示干员字段；选择敌人时，中间表单显示敌人字段。

模板列表显示当前类型下所有模板。每个条目显示模板名称和 ID。点击条目会选中该模板并刷新属性表单与范围编辑器。

`新建` 会在当前类型下创建一个默认模板。干员默认是高台自定义干员，敌人默认是可阻挡普通敌人。

`复制` 会复制当前选中模板，生成一个新的 ID 和名称，便于基于已有模板改数值。

`删除` 会删除当前选中模板。删除后会自动选择同类中的下一个模板；如果没有剩余模板，则表单显示空状态。

### 中间：干员属性表单

干员表单用于编辑我方单位模板。

`ID` 是干员模板唯一标识。部署、保存和自定义目录合并都依赖它。

`名称` 是游戏内显示名称。

`职业` 决定干员分类和职业部署上限统计，可选先锋、近卫、重装、狙击、术士、医疗、自定义。

`职业显示` 是界面上展示的职业文字，可与职业分类不同。

`部署地形` 决定干员能部署在哪里。`ground` 对应路径地面格，`high` 对应高台格。

`费用` 是部署该干员消耗的费用。

`生命` 是最大生命值。

`防御` 用于物理伤害计算。物理伤害为攻击力减防御力，不保底。

`法抗 0-100` 用于法术伤害减算。例如 25 表示减少 25% 法术伤害。

`攻击间隔` 是普通攻击间隔，单位为秒。

`阻挡` 是可阻挡敌人的数量。敌人的反阻挡数高于该值时，可以穿过该干员。

`目标策略` 决定普通攻击或治疗选择目标的规则。干员可用策略包括阻挡优先、出口优先、飞行优先、高防优先、低生命优先。

`颜色` 决定该干员在战场和 UI 中的主题色。

干员基础表单不再直接设置攻击力或攻击类型。普通攻击造成的伤害、神经损伤或治疗量，统一在“普通攻击组件”中配置；技能造成的效果统一在对应技能的“技能效果组件”中配置。

### 中间：敌人属性表单

敌人表单用于编辑敌方单位模板。

`ID` 是敌人模板唯一标识。地图时间轴中的敌人类型需要引用这个 ID。

`名称` 是敌人显示名称。

`生命` 是最大生命值。

`攻击` 是基础攻击数值，也用于兼容旧字段。

`防御` 用于抵消物理伤害。

`法抗 0-100` 用于减少法术伤害。

`速度` 是沿路径移动的速度。

`攻击间隔` 是敌人普通攻击间隔。

`击败费用` 是击杀该敌人后返还给玩家的费用。

`目标价值` 是敌人进入终点后扣除的基地生命值。例如目标价值为 8，则漏掉该敌人会扣 8 点生命。

`反阻挡数` 是突破阻挡的能力值。当敌人的反阻挡数大于干员阻挡数时，该敌人可以穿过该干员。

`攻击类型` 是传统兼容字段，可选物理或法术。实际攻击可以在普通攻击组件中配置为多个组件。

`目标策略` 决定敌人攻击目标，可选阻挡优先、最近目标、低生命优先。

`可阻挡` 控制敌人是否能被地面干员阻挡。

`飞行` 表示敌人是否为飞行单位。飞行单位不会被地面阻挡，通常需要远程干员处理。

`精英` 是标记字段，用于区分强敌。

`Boss` 是标记字段，用于区分首领单位。

`颜色` 决定敌人在战场、情报面板和效果中的主题色。

### 中间：普通攻击组件

普通攻击组件用于配置一次普通攻击中包含哪些效果。一个普通攻击可以同时包含多个组件，例如物理 + 法术，或治疗 + 神经损伤。

`物理` 按钮会新增一个物理伤害组件。

`法术` 按钮会新增一个法术伤害组件。

`神经` 按钮会新增一个神经损伤组件。神经损伤会积累到目标的神经条，满后清空并造成额外生命损失。

`治疗` 按钮会新增一个治疗组件。治疗组件会回复我方目标生命，医护干员治疗其他干员时会显示治疗动画。

每一行组件包含：

`类型下拉框` 可切换该组件为物理、法术、神经或治疗。

`数值输入框` 是该组件的基础数值。

`删除` 会移除该普通攻击组件。普通攻击组件可以全部删除，删除后该单位的普通攻击不会产生对应效果。

### 中间：技能编辑区

技能区用于配置干员技能或敌人技能。

干员最多 3 个技能。敌人技能数量不受这个 UI 上限限制。

`新增技能` 会为当前模板添加一个默认技能。干员默认新增强化类手动技能，敌人默认新增生命阈值触发技能。

每个技能卡片顶部显示技能名称，并提供 `删除` 按钮。

`技能ID` 是技能唯一标识。

`名称` 是技能显示名称。

`简介` 是技能说明文本，会显示在干员信息面板或敌人信息中。

`触发` 可选手动、自动、生命阈值。手动技能需要玩家点击释放；自动技能技力满后自动释放；生命阈值主要用于敌人技能，生命比例低于阈值时触发一次。

`类型` 可选回费、强化、下次攻击、瞬时治疗。回费用于立即增加费用；强化用于持续增益；下次攻击用于强化下一次攻击；瞬时治疗用于立即治疗目标。

`SP` 是技能所需技力。干员技能会在战场上显示技力条，释放持续技能时技力条会随持续时间从满变空。

`生命阈值%` 是生命阈值触发技能使用的百分比。敌人生命百分比降到该值或以下时释放。

`持续` 是持续类技能或效果持续时间。

`数值` 是技能的通用数值字段，例如回费量或瞬时治疗量。

`自疗比例` 是按自身最大生命百分比回复生命的比例，例如 0.3 表示回复 30% 最大生命。

`攻击倍率` 是技能激活时对攻击力的乘算倍率。

`防御倍率` 是技能激活时对防御力的乘算倍率。

`间隔倍率` 是技能激活时对攻击间隔的乘算倍率。小于 1 表示攻击更快。

`下次倍率` 是下次攻击类技能对下一次攻击的倍率。

每个技能卡片下方还有“技能效果组件”。这里的按钮和行编辑方式与普通攻击组件一致，可为技能添加物理伤害、法术伤害、神经损伤或治疗效果。技能组件独立于普通攻击组件，适合制作带额外伤害、混合伤害或治疗效果的主动/自动/阈值技能。

### 右侧：范围面板

范围面板用于编辑普通攻击范围或技能范围。当前实现使用 11x11 手绘格子，以中心格 `(0,0)` 作为单位自身所在位置。

`攻击范围` 按钮表示当前正在编辑普通攻击范围。

技能名称按钮表示当前正在编辑对应技能的技能范围。只有已存在技能时才会显示技能范围按钮。

预设按钮用于快速套用常见范围：

- `近战`：只包含自身格。
- `菱形2`：曼哈顿距离 2 内的菱形范围。
- `菱形3`：曼哈顿距离 3 内的菱形范围。
- `直线`：面向正前方的直线范围。
- `前方`：面向正前方的块状范围。
- `十字`：上下左右展开的十字范围。
- `广域`：较大的治疗或支援范围。

范围网格中：

- 中心格是单位自身位置。
- 高亮格表示当前范围包含该相对位置。
- 点击任意格子会切换该格是否包含在范围内。
- 普通攻击范围会写入模板的 `normalAttack.range`。
- 技能范围会写入对应技能的 `range`。

干员在战斗中部署时可以指定方向，因此范围会以编辑时的正方向为基础，部署后根据朝向旋转。

### 右侧：JSON 面板

JSON 文本框用于查看、复制、手动编辑或粘贴自定义目录 JSON。

`导出` 会把当前干员和敌人模板写入该文本框。

`导入` 会读取文本框内容并替换当前自定义目录。

校验面板会显示“自定义数据有效”或具体错误。错误通常来自 ID 格式、缺少必填字段、数值越界、技能数量超限、范围格式不合法等。

消息区会显示最近一次操作结果，例如“已保存到 localStorage”“JSON 已导入”“已更新”等。

## 常见工作流

制作新地图时，通常先设置地图名称、ID、尺寸和初始费用；再用格子工具绘制路径、高台和障碍；然后新增路径并在路径格上添加路径点；最后配置时间轴和节点动作。完成后使用“保存到地图库”用于本地游玩，或使用“下载 JSON”保存为文件。

制作新敌人时，通常先在自定义编辑器切到“敌人”，点击“新建”，配置 ID、名称、生命、防御、速度、目标价值和普通攻击组件；如果需要远程攻击，在右侧设置攻击范围；如果需要生命阈值技能，点击新增技能并配置阈值、范围和效果。

制作新干员时，通常先在自定义编辑器切到“干员”，点击“新建”，设置职业、部署地形、费用、生命、防御、阻挡和普通攻击组件；再用右侧范围面板设置攻击范围；最后按需要添加最多三个技能并配置触发方式、SP、持续时间、倍率和技能效果组件。
